## 🚀 Установка и запуск

```bash  
Чтобы запустить проект:  
git clone https://github.com/frankiz-id/sea_battle.git  
cd sea_battle  
poetry install  

Управление в игре  
Главное меню (выбор цифрами 1-6):  
1️⃣ Play vs Weak AI - игра против простого ИИ  
2️⃣ Play vs Strong AI - игра против продвинутого ИИ  
3️⃣ Play vs Friend - игра на одном устройстве  
4️⃣ Settings - настройки игры  
5️⃣ Help - справка по управлению  
6️⃣ Exit - выход из игры  

Меню настроек (клавиша 4):
Field Size (5-16) - изменить размер поля  
Ship Configuration - настроить корабли  
Placement Mode - ручная/авто расстановка  
Back - вернуться в меню  

Управление в настройках:
↑/↓ - выбор пункта
Enter - подтвердить
ESC - назад

⚓ Ручная расстановка кораблей:
Нажмите 1-4 для выбора размера корабля
Кликайте ЛКМ по клеткам для размещения
Для сброса - снова нажмите 1-4
